01 — Market Intelligence Module

Not just contacts.
Decision intelligence.

The market entry module is the most data-dense view. It aggregates competitor analysis, prospect rankings, signal feeds, and priority matrices into a single scrollable dashboard — all built inside the CRM as an embedded module.

The insight that drove the design: a CRM shouldn't just store contacts. It should help you decide who to call next and why.

02 — 3D Relationship Graph

Every relationship
in one space.

The standout feature: a force-directed 3D graph that maps every contact, organization, deal, and signal as a node in 3D space. Edges represent relationships — "introduced by", "works at", "connected to deal", "linked to signal".

Built with 3D Force Graph (a Three.js wrapper) + a custom layout engine that runs in a Web Worker to keep the UI at 60fps even with 200+ nodes.

You can orbit, zoom, click any node to see its details, and filter by type. Hovering an edge shows the relationship metadata inline.

Why 3D? In a flat list you lose relationship context. In 3D, clusters emerge naturally — you can see "these 4 people all know each other through this org" at a glance, without any manual grouping.

03 — Claude Sonnet Chat Interface

Query your CRM
in plain language.

Integrated a streaming Claude Sonnet chat directly inside the CRM. The assistant has access to the full database schema and can answer questions like:

  • "Who are the warmest prospects this week?"
  • "Which contacts haven't we talked to in 30 days?"
  • "Summarize all interactions with Banco Chile"
  • "What signals are relevant to our banking pipeline?"

Built with the Anthropic SDK streaming API — responses appear token by token, with a custom bubble component (`ForesightAgentBubble.astro`) that handles markdown rendering inline.
